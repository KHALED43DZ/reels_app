# تطبيق صانع موارد مسلسلات الريلز (PWA)

تطبيق ويب تفاعلي قابل للتثبيت على الهاتف كـ Progressive Web App.

## محتويات المشروع:
- `index.html`: واجهة المستخدم.
- `style.css`: التنسيقات والألوان.
- `app.js`: البرمجة والربط مع الذكاء الاصطناعي وإنشاء حزمة ZIP.
- `manifest.json`: إعدادات تثبيت التطبيق على الشاشة الرئيسية للهاتف.

## طريقة الرفع والاستضافة على GitHub Pages:
1. قم بفك الضغط عن هذا الملف.
2. ارفع كافة الملفات إلى مستودع (Repository) جديد في GitHub.
3. اذهب إلى **Settings** > **Pages**.
4. اختر الفرع `main` واضغط **Save**.
5. افتح الرابط الناتج من الهاتف وقدم طلب "تثبيت التطبيق على الشاشة الرئيسية".
